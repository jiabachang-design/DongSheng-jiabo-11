# 错题库 · Obsidian Vault

个人错题与知识管理库。配合 Obsidian 使用。

## 目录结构

```
错题库/
├── 高数/
│   ├── 极限/
│   ├── 导数/
│   ├── 微分/
│   ├── 积分/
│   └── 级数/
├── 线代/
│   └── 行列式与矩阵/
└── 英语/
    └── 翻译与写作/

模板/
└── 错题模板.md
```

## 使用方法

1. 用 Obsidian 打开本仓库根目录作为 Vault
2. 新错题：复制 `模板/错题模板.md`，改名为题目主题，放进对应章节文件夹
3. 每周日重做一遍，会的删，不会的留
4. 病根务必写在 frontmatter 的 `病根` 字段，方便按病根筛选

## 错题四要素

| 字段 | 含义 |
|------|------|
| 病根 | 概念没懂 / 忘记公式 / 粗心 / 方法不会 |
| 错哪 | 具体错在哪一步 |
| 对解 | 正确解法（只写卡住的那步到答案） |
| 提醒 | 一句话人话提醒 |
