## 病根说明

| 病根 | 典型表现 |
|------|----------|
| 投影关系看错 | 长对正、高平齐、宽相等没对上；主视图看错方向 |
| 图形表达不合规范 | 线型用错、虚线该实线、断面线方向错、中心线漏画 |
| 尺寸标注漏错 | 漏尺寸、多尺寸、尺寸链封闭、基准选错、直径/半径符号漏 |
| 空间想象不到位 | 立体的截交线/相贯线想不出来，想反了 |
| 粗心 | 比例看错、箭头方向画反、图线不封口、漏擦多余线 |

## 通用四要素（沿用总模板）

| 字段 | 含义 |
|------|------|
| 病根 | 上面五类之一 |
| 错哪 | 具体哪一步错，比如"截交线转折点没求""φ 没写""俯视图宽没量" |
| 对解 | 只写卡住那步到答案的标准画法 |
| 提醒 | 一句话人话提醒 |
